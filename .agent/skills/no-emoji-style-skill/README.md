# No Emoji Style Skill

This project introduces a new agent skill designed to avoid the use of emojis in favor of standard icons. The goal is to promote consistency, clarity, and accessibility in communication and documentation.

## Purpose

The No Emoji Style Skill provides guidelines and best practices for implementing a communication style that utilizes standard icons instead of emojis. This approach is particularly beneficial in professional settings where clarity and uniformity are paramount.

## Project Structure

- **SKILL.md**: Contains the main instructions and guidelines for implementing the No Emoji Style Skill.
- **examples/icon-usage.md**: Provides examples of how to effectively use standard icons in place of emojis, showcasing best practices and scenarios.
- **references/icon-guidelines.md**: Outlines the guidelines for selecting and using icons, including design principles and accessibility considerations.

## Setup Instructions

1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Review the `SKILL.md` file for detailed instructions on how to implement the skill.
4. Explore the `examples` and `references` directories for practical usage and guidelines.
